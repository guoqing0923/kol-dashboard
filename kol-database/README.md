# 土耳其KOL达人库

本系统整合历史投放明细 + 4月数据 + Codeck API实时数据，支持周期性更新与复盘。

## 文件说明

| 文件 | 说明 |
|------|------|
| `turkey_kol_database.xlsx` | 主数据库（视频明细 / 达人汇总 / 达人池）|
| `update_kol_database.py` | 更新脚本 |
| `README.md` | 本说明文档 |

---

## 数据库结构

### Sheet 1：视频明细
每条视频一行，包含：达人、宣发期、平台、视频类型、发布日期、花费、VV、CPM、互动率、各维度得分、综合评分、评级、操作建议、数据来源。

### Sheet 2：达人汇总
按达人聚合，含：合作次数、总花费、总VV、平均CPM、各期评级趋势、最新等级、操作建议。

### Sheet 3：达人池
达人背景信息：视频类型、平台、过往花费、评级、粉丝量、联系方式等。

## 使用方法

### 首次初始化（已完成）
```bash
cd /Users/guoqing/Documents/UG\ Marketing/kol-database
python3 update_kol_database.py --init
```

### 每周例行更新
```bash
# 拉取最近7天新数据
python3 update_kol_database.py --days 7
```

### 月度复盘
```bash
# 拉取指定月份全量数据
python3 update_kol_database.py --month 2026-05
```

### 全量同步
```bash
# 全量重新拉取所有TR数据并追加去重
python3 update_kol_database.py --all
```

## 评级标准

### 短视频（TikTok / Instagram / Shorts）满分12分

| 维度 | 4分 | 3分 | 2分 | 1分 |
|------|-----|-----|-----|-----|
| 曝光力 | VV > 10万 | 5万-10万 | 1万-5万 | < 1万 |
| CPM | < $20 | $20-30 | $30-50 | >= $50 |
| ER(IG) | > 4% | 2-4% | 0.8-2% | < 0.8% |
| ER(TK) | > 10% | 6-10% | 3-6% | < 3% |

**等级：S=11-12分 / A=8-10分 / B=5-7分 / C=<=4分**

### 长视频（YouTube）满分16分（无PV时满分12分）

| 维度 | 4分 | 3分 | 2分 | 1分 |
|------|-----|-----|-----|-----|
| 曝光力 | VV > 1万 | 5000-1万 | 2000-5000 | < 2000 |
| CPM | < $100 | $100-200 | $200-400 | >= $400 |
| ER | > 7% | 5-7% | 2-5% | < 2% |
| 转化力(PV) | > 100 | 50-100 | 10-50 | <= 10 |

**等级：S=14-16分 / A=10-13分 / B=6-9分 / C=<=5分**

## 评级颜色说明

| 等级 | 颜色 | 操作建议 |
|------|------|----------|
| S | 绿色 | 必须复投，优先争取独家/季度合作 |
| A | 浅绿 | 进入复投候选池，次月优先联系 |
| B | 黄色 | 观察区，可考虑次月再合作一次测试稳定性 |
| C | 红色 | 原则上淘汰 |

## 注意事项

1. API Token 存储在 `~/.verdent/secrets/codeck.json`，请勿外泄
2. 更新脚本会自动去重（以达人+宣发期+平台+发布日期为唯一键，API数据以视频ID去重）
3. 历史数据中没有发布日期字段，去重仅依赖宣发期+平台
4. API数据中官网PV暂无，长视频评分默认按满分12分计算
